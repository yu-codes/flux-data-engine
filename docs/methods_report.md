# Flux Data Engine — 方法與成果報告

> 版本：v3.0.0 | 日期：2026-05-26

---

## 1. 專案概述

Flux Data Engine 是一套基於歷史類比方法的多災害影響預測系統。目前聚焦於**颱風路徑分類預測**，利用台灣中央氣象署 (CWA) 定義的 9 類路徑分類標準，為新的颱風事件找出最相似的歷史案例並預測其路徑類型。

**核心價值**：透過類比歷史颱風，協助防災決策者快速掌握潛在影響範圍、降水量級與災害風險。

## 3. 預測方法

### 3.1 Combined RRF 優化版 ⭐ 推薦

**準確率：79.8% (158/198)**

融合三種相似度指標的 Reciprocal Rank Fusion 方法：

- **KNN（特徵加權）**：對 11 維摘要特徵計算加權歐式距離，顯著特徵（min_distance_to_taiwan, mean_angle, is_landfall）權重提升 2-3 倍
- **DTW（時序路徑）**：使用物理標準化的極座標系統 (r, θ, wind, pressure) 計算軌跡相似度，最佳權重 [1.0, 0.5, 1.0, 0.5]
- **Rule-Based（幾何分類）**：基於路徑幾何分析的規則式分類器

**最佳化參數**（透過網格搜索確定）：
| 參數 | 值 | 意義 |
|------|-----|------|
| α (KNN權重) | 0.10 | KNN 貢獻度 |
| Rule 權重 | 0.40 | 規則式貢獻度 |
| DTW 權重 | 0.50 | 時序相似度貢獻度 |
| RRF k | 30 | 排名平滑常數 |

### 3.2 Rule-Based 幾何分類

**準確率：79.8% (158/198)**

純規則式方法，基於颱風路徑的幾何特徵判斷路徑分類：
- 最接近台灣距離
- 通過方向角 (heading)
- 是否穿越台灣本島
- 登陸位置文字解析
- 緯度/經度判斷

**優勢**：完全可解釋、無需訓練、即時推論。

### 3.3 Combined RRF 原版

**準確率：74.7% (148/198)**

使用預設參數的融合方法，作為基線對照。

### 3.4 KNN 優化版

**準確率：63.6% (126/198)**

只使用 3 個顯著相關特徵的加權 KNN：
- `min_distance_to_taiwan` (Spearman ρ = -0.384)
- `is_landfall` (ρ = 0.296)
- `mean_angle` (ρ = -0.208)

## 4. 優化過程與依據

### 4.1 KNN 特徵篩選

透過 Pearson + Spearman 相關性分析，從 11 維特徵中篩選與降水量顯著相關的特徵。結果僅 3 個特徵通過顯著性篩選 (p < 0.01)，說明多數特徵對降水預測的貢獻有限。

### 4.2 DTW 參數搜索

對 10 組四維權重組合進行 Leave-One-Out 交叉驗證：
- 最佳權重：[1.0, 0.5, 1.0, 0.5]（距離與風速維度加重）
- 物理標準化：r/300km, θ/π, wind/100kt, (pressure-950)/50mb

### 4.3 RRF 權重分析

預計算所有排名後快速掃描參數空間：
- Rule-Based 在融合中的最佳權重高達 0.4，反映其在路徑分類任務上的核心優勢
- DTW 權重 0.5 > KNN 0.1，說明時序路徑相似度比摘要特徵更重要

### 4.4 Rule-Based 改進歷程

| 版本 | 準確率 | 改進內容 |
|------|--------|----------|
| 初始 | 75.8% | 基礎規則 |
| v2 | 78.3% | Cat 6 方向角範圍收窄 + Cat 8 條件放寬 |
| v3 | 79.8% | 登陸解析重寫 + 東岸排除修正 |

## 5. 系統架構

```
[Vue 3 前端] → [Nginx 反向代理] → [FastAPI 後端] → [Python ML 引擎]
     :3000              :80              :8000
```

- **後端**：FastAPI + uvicorn，啟動時預載所有模型
- **前端**：Vue 3 + Vite + Vue Router，依災害 domain 分目錄
- **部署**：Docker Compose 一鍵啟動

---

## 6. 後續規劃

1. **Rule-Based 繼續優化**：目標 80%+，分析剩餘 40 個錯誤案例的共同模式
2. **多災害擴展**：加入地震、洪水等 domain
3. **降水量預測模型**：從類比結果延伸為定量預測
4. **模型 API 上線**：配合即時颱風資料進行即時預測
